Ask your AI about your Renpho data. Nothing installed, nothing hosted.

This Renpho MCP server is read-only and runs in a Docker container. It answers questions about your Renpho scale and tape-measure history from Claude or any MCP client.

QuickstartView on GitHub

Why a container

Contained

Runs as a non-root user in a Docker image built from a locked dependency file. Nothing is installed on your machine except the image.

Stays local

No account on a hosted service. Your password sits in the container's environment and is sent to Renpho by the SDK. It is read-only: no tool can change your account.

Scale and tape

Ask about weigh-ins and tape-measure girth (waist, hip, arms, thighs) in the same conversation.

Quickstart

You need Docker and a Renpho Health account (email and password).

  1. Build the image 
    git clone https://github.com/ifthenelse/Renpho-API-MCP-Server.git
cd Renpho-API-MCP-Server
docker build -t renpho-mcp .
  2. Store your credentials in a git-ignored file 
    cp .env.example .env
# edit .env: RENPHO_EMAIL=you@example.com  RENPHO_PASSWORD=your-password
  3. Add it to your MCP client. Claude Code: 
    claude mcp add renpho -- docker run -i --rm --env-file "$PWD/.env" renpho-mcp
    Other clients, in their MCP config: 
    {"mcpServers": {"renpho": {"command": "docker",
  "args": ["run", "-i", "--rm", "--env-file", "/abs/path/to/.env", "renpho-mcp"]}}}
  4. Ask. "Summarize my Renpho data." "Show my weekly average weight and body fat since January." "How has my waist changed this year?"

Three tools

ToolWhat it does
summaryLatest reading, 30-day change per metric, record count and date range. Start here.
measurementsScale history as a compact table. Pick metrics (weight, bodyfat, muscle, water, bmr and more), filter by date, and average by day, week or month.
girthTape-measure history in centimetres: neck, chest, waist, hip, arms, thighs, calves and waist-to-hip ratio.

How answers stay short

Every tool returns plain tab-separated text with one header row, rounded numbers and blank cells where nothing was measured. You choose the columns, a date range and a period, so a year of weigh-ins can come back as a dozen rows. History is fetched once and cached for 15 minutes.
